## Archiving Convention

`change_log.md` stays newest-first and holds the **active/current phase**. When it grows past roughly 25-30 entries, archive the oldest coherent phase (a natural stretch of related work, not necessarily a calendar boundary — this project's entries mostly share one date) into a new numbered file here, oldest-entries-first, and add a row to this table. Leave the live file's remaining entries untouched aside from removing the archived ones.
