**2026-08-08** — Round 1 (Priya persona test): added a "has existing goal" state to prototype/index.html (demo toggle + Europe Trip goal variant, with a "Redirect $18 to Europe Trip" action tied to the week's insight) — **Rationale:** in-character testing surfaced that the prototype only modeled the no-goal state, which broke trust immediately for a user who already has a goal ("if it doesn't know I have a goal, can I trust the $184 number either?"); the fix makes the nudge/goal-progress logic branch on actual goal state instead of assuming none exists — **Owner:** me

**2026-08-08** — Round 2 (Tom persona test): replaced the no-goal state's "Set a savings goal" full-commitment CTA with a one-tap "Try it: redirect $18" starter-fund action, demoted full goal setup to an optional secondary link ("or set up a full goal instead"), and added a post-action upgrade path ("Turn this into a real goal") — **Rationale:** in-character testing showed a skeptical, app-fatigued user reads any upfront ask to "set a goal" as the opening move of a pattern he's already abandoned three times; the friction is ask-size relative to trust earned, not the goal concept itself — a smaller first action lets trust build before asking for commitment — **Owner:** me

**2026-08-08** — Round 3 (Amara persona test): softened the nudge from a prescriptive "redirect $18" to a framed option ("if savings is a priority right now..."), added a fine-print disclosure clarifying the starter fund is a real, verifiable sub-account (not a cosmetic number) and explicitly naming what the app doesn't know (debt, other priorities), and made done-state copy explicit that it's a real transaction — **Rationale:** in-character testing surfaced that a financially savvy, high-trust-bar user identified a real risk: defaulting to "redirect to savings" could be objectively bad advice for someone carrying high-interest debt, and she also questioned whether the redirected amount was a real transaction or just a UI number; within the no-new-integrations constraint, the fix is honesty about what the app doesn't know rather than a false claim of full personalization — **Owner:** me
